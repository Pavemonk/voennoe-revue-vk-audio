# Радио КП — Прямой эфир

Android-проект минимального аудиоплеера прямой трансляции Радио КП в VK Видео. Основной ориентир — программа «Военное ревю полковника Баранца» в 16:00–17:00 МСК.

## Что делает

- По кнопке «Найти эфир» открывает страницу прямых эфиров Радио КП в VK Видео: `https://vkvideo.ru/@radiokp/lives`.
- Ожидает, пока страница VK запросит метаданные активной трансляции, и пытается извлечь свежую ссылку HLS из ответа `video.getVideoDiscover`.
- Передаёт временный HLS-адрес нативному проигрывателю Media3.
- Отключает видеодорожку в селекторе дорожек, чтобы воспроизводить звук, а не показывать/декодировать видео. После получения HLS-ссылки уничтожает WebView, освобождая его ресурсы; при запуске приложения страница VK автоматически не загружается.
- Продолжает воспроизведение в foreground-службе Android с уведомлением и кнопками Play/Pause/Stop.
- Не использует MP3-поток Радио КП.

## Важно: статус сборки

Это **исходный Android-проект, а не готовый APK**. В среде, где проект подготовлен, нет Android SDK / Android Gradle Plugin и нет сетевого доступа для загрузки необходимых компонентов, поэтому APK не удалось собрать и проверить на телефоне. Не устанавливайте проект как готовое приложение: сначала его нужно собрать и проверить.

Метод обнаружения HLS-потока экспериментальный. VK может поменять внутренний API, авторизацию или формат ответа. Особенно важно испытать его во время настоящего эфира. Если ссылка не обнаружится, откройте вкладку эфиров в самом приложении и вручную нажмите на текущий эфир; если VK изменит API, потребуется поправить извлечение.

## Сборка APK в Android Studio

1. Установите Android Studio и Android SDK Platform 35. Для Gradle нужен JDK 17 или совместимый JDK, поддерживаемый установленной версией Android Studio.
2. Откройте папку `voennoe-revue-vk-audio` как проект.
3. Дождитесь Gradle Sync и разрешите Android Studio загрузить плагины/зависимости.
4. В Windows из папки проекта можно выполнить `gradlew.bat assembleDebug` (скрипт загрузит Gradle 8.10.2); либо выберите **Build → Build APK(s)** в Android Studio.
5. При успешной сборке APK будет здесь: `app/build/outputs/apk/debug/app-debug.apk`.

В проекте используется Android Gradle Plugin 8.8.2 и AndroidX Media3 1.5.1.

## Сборка без установки Android Studio (через браузер)

В проект добавлен GitHub Actions workflow `.github/workflows/build-apk.yml`. Он собирает APK на облачном сервере GitHub; Android Studio на личный компьютер устанавливать не нужно. Нужен аккаунт GitHub и доступ к сайту `github.com`.

1. Распакуйте ZIP встроенным средством Windows в Проводнике.
2. На GitHub создайте новый репозиторий (например, `voennoe-revue-vk-audio`).
3. В репозитории выберите **Add file → Upload files** и загрузите содержимое папки проекта целиком: в корне репозитория должны быть `app`, `.github`, `build.gradle`, `settings.gradle`, `gradlew` и остальные файлы проекта. Нажмите **Commit changes**.
4. Откройте вкладку **Actions**. Сборка запустится автоматически после коммита; при необходимости откройте workflow **Build Android APK** и нажмите **Run workflow**.
5. Когда задача завершится успешно, откройте её страницу и скачайте артефакт `voennoe-revue-vk-audio-apk` из раздела **Artifacts**. Распакуйте скачанный артефакт — внутри будет `app-debug.apk`.

Облачная сборка только компилирует приложение. Она не подтверждает, что VK сейчас отдаёт поток в ожидаемом формате: обнаружение HLS в этом проекте экспериментальное и должно быть проверено во время реального эфира.

## Первый запуск

1. Откройте приложение и нажмите «Найти эфир».
2. Если VK просит авторизоваться, выполните вход во встроенной странице.
3. Если текущий эфир не открылся автоматически, нажмите на его карточку. Как только приложение распознает HLS, оно закроет и уничтожит WebView и переключится на нативное воспроизведение только звука.
4. При прослушивании можно погасить экран; управление останется в уведомлении Android.
5. Для нового эфира нажмите «Найти эфир» снова. Страница нужна только на время поиска ссылки; в фоне она не остаётся.

Если автоопределение не сработало, это не гарантирует, что VK не отдаёт аудио: значит, ответ потока не совпал с текущим извлекателем или VK изменил API.

## Конфиденциальность

Проект не содержит рекламных SDK и не отправляет данные на отдельный сервер. Загрузка страницы, авторизация и запросы потоков выполняются непосредственно к VK и его CDN. Авторизация, если она нужна, хранится средствами WebView на устройстве.

Альтернативно на Windows можно запустить `build-apk.bat`. Скрипт скачает Gradle при первом запуске, выполнит сборку и выведет путь к APK. Android SDK Platform 35 должен быть установлен, а Android SDK должен быть доступен через Android Studio/`ANDROID_HOME` или `local.properties`.
